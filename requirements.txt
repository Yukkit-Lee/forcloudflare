  海大停车场一键缴费 - 需求 & 技术文档
  2026-06-13
══════════════════════════════════════════

【目标】
  停车场一键缴费 + 停车看板，免手动输入车牌。

【系统架构】
  前端页面 → server.js(:3000) → 海大API
               ├─ getInRecordByPlateNo  查询记录
               └─ bill                 查询费用

【API清单】
  GET /api/search?plate=xxx         → { payUrl, parkId, enIndexCode }
  GET /api/search?plate=xxx&redirect=1  → 302跳转缴费
  GET /api/detail?plate=xxx         → { 入场时间, 费用, payUrl, ... }

【页面】
  /          快捷缴费页 —— 一键跳转
  /board     便捷面板 —— 停车看板 + 后续扩展

【停车看板功能】
  车牌 / 入场时间 / 停车时长（实时）/ 应缴金额
  48h拉黑进度条 + 三色警告
  一键缴费按钮

【待扩展】
  Deadline看板 / Token消耗看板 / 计算器 / 其他工具

【部署】cd code && npm install && node server.js

【健身房监控】
  本地 dashboard 展示当前在线人数、今日实时曲线和昨日真实数据曲线。
  昨日数据由本地 /api/gym/yesterday-data 按当前日期动态读取。
  2026-07-29 10:51 之前的缺失时段，暂使用 2026-07-30 对应时刻数据补齐；
  2026-07-31 起昨日数据为完整的 2026-07-30 文件，不再触发补齐逻辑。
  图例使用“今日实时”和“昨日参考”，昨日曲线使用灰色虚线。
  健身房上游接口必须直连，不走本机代理；本地版使用 Node 原生 fetch 请求。
  今日曲线必须读取服务器持续采集的当天数据文件，而不是只依赖浏览器 localStorage。
  X 轴范围固定显示 0:00-24:00，小时标签不补前导零。
  今日实时曲线末端显示一个跟随最新采样位置的呼吸闪烁蓝点。
  昨日 10:51 前按每 5 分钟补齐数据点，确保早时段曲线连续。
  蓝点圆心必须使用蓝线最后绘制点的相同坐标，确保与曲线末端重合。
  后台自动采集必须与健身房接口代理使用同一条直连 fetch 链路，不得继续使用 axios 代理链路。
  data/dataLog 记录自动采集尝试、成功、失败、恢复间隔、写入来源和服务启动信息。
